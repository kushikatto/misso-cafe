# راه‌اندازی سفارشات Misu

## 1) اجرای دیتابیس
در Supabase → SQL Editor فایل `orders-migration.sql` را کامل اجرا کنید. این فایل جداول سفارش، ردیف‌های سفارش، شمارنده شماره سفارش روزانه و خلاصه گزارش را می‌سازد و توابع ثبت سفارش، تأیید، تسویه و آرشیو را اضافه می‌کند.

**این فایل را فقط یک بار اجرا کنید.** فایل قبلی `supabase-setup.sql` یا `storage-setup.sql` را دوباره اجرا نکنید.

## 2) انتشار سایت
تمام محتویات پوشه را در ریشه Repository گیت‌هاب جایگزین کنید و Commit کنید. GitHub Pages باید از شاخه `main` و پوشه `/(root)` منتشر شود.

## 3) گردش کار
- مشتری محصول را به سبد اضافه و نامش را وارد می‌کند؛ قیمت‌ها در سمت سرور از جدول منو خوانده می‌شوند.
- مدیر در تب سفارشات، سفارش جدید را تأیید می‌کند. شماره روزانه از ۱ شروع می‌شود و زمان ثبت/تأیید نیز ذخیره می‌شود.
- مدیر می‌تواند یک سفارش را جداگانه یا چند سفارش را با هم تسویه کند. مجموع نقدی و کارت باید دقیقاً برابر مبلغ کل باشد.
- پس از تسویه، پنجره چاپ رسید مرورگر باز می‌شود. برای چاپ از پرینتر شبکه‌ای باید سیستم مدیر به همان شبکه متصل باشد و پرینتر به‌عنوان چاپگر سیستم‌عامل نصب شده باشد.
- گزارش روزانه را دانلود کنید و سپس «بستن روز و آرشیو» را بزنید. خلاصه فروش و آمار محصولات در `daily_sales_summaries` ثبت می‌شود؛ سفارش‌ها و ردیف‌های آن‌ها برای حفظ سوابق حذف نمی‌شوند.

## 4) چاپگر SKY E200 از طریق LAN
این نسخه رسید را با پنجره چاپ استاندارد مرورگر آماده می‌کند. برای چاپ بی‌وقفه و بدون پنجره مرورگر از طریق IP/ESC-POS، یک سرویس محلی کوچک (bridge) روی کامپیوتر صندوق لازم است؛ آدرس IP، پورت شبکه و پروتکل چاپگر باید از تنظیمات خود دستگاه/دفترچه آن مشخص شود. این بخش به دلیل نداشتن IP و پورت واقعی دستگاه هنوز فعال نشده است. فعلاً چاپ استاندارد سیستم‌عامل قابل استفاده است.

## 5) نصب اپ مدیر
در Chrome یا Edge، سایت را باز کنید و از منوی مرورگر گزینه Install page as app / نصب برنامه را انتخاب کنید. PWA برای پنجره مستقل و کش فایل‌های پایه تنظیم شده است؛ برای نمایش آیکون اختصاصی باید فایل‌های آیکون PNG نیز اضافه شوند.

## نکات
- ساعت و شماره سفارش بر اساس منطقه زمانی Asia/Tehran ساخته می‌شود.
- گزارش TXT با تاریخ شمسی نام‌گذاری می‌شود.
- سفارش‌ها تا وقتی مدیر روز را آرشیو نکند، در جدول سفارشات باقی می‌مانند.
