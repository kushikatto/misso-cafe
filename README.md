# منوی دیجیتال — نسخه شروع

این پروژه یک منوی دیجیتال فارسی با طراحی Minimal Light است. مشتری منو را بدون ورود می‌بیند؛ ادمین پس از ورود می‌تواند صفحه و محصول بسازد و قیمت‌ها و تصاویر را مدیریت کند. سفارش آنلاین در این نسخه وجود ندارد.

## فایل‌ها
- `index.html` رابط کاربری
- `styles.css` طراحی واکنش‌گرا
- `app.js` منطق منو و پنل ادمین
- `config.example.js` نمونه تنظیمات اتصال
- `supabase-setup.sql` ساخت جدول‌ها، دسترسی‌ها و فضای تصاویر

## ۱) راه‌اندازی Supabase
1. در Supabase یک پروژه جدید بسازید.
2. از بخش SQL Editor محتوای `supabase-setup.sql` را اجرا کنید.
3. از Authentication > Users یک کاربر بسازید (ایمیل و رمز عبور مدیر).
4. شناسه UUID کاربر را بردارید و دستور آخر فایل SQL را با UUID واقعی اجرا کنید تا نقش او `admin` شود.
5. در Authentication > Settings، ثبت‌نام عمومی را در صورت عدم نیاز خاموش کنید. برای مشتری فقط مشاهده منو لازم است.
6. از Project Settings > API مقادیر Project URL و anon/public key را بردارید.

## ۲) تنظیم پروژه
1. `config.example.js` را کپی و نام کپی را `config.js` کنید.
2. مقادیر Supabase URL و anon/public key و نام کافه را وارد کنید.
3. فقط کلید `anon` یا `publishable` را در فرانت‌اند قرار دهید؛ کلید `service_role` محرمانه است و نباید منتشر شود.
4. در مرورگر `index.html` را باز کنید. بدون تنظیم Supabase فقط پیش‌نمایش نمونه فعال است.

## ۳) انتشار روی GitHub Pages
1. یک repository جدید در GitHub بسازید.
2. تمام فایل‌های پروژه را در ریشه repository آپلود کنید؛ `config.js` را هم اضافه کنید.
3. بروید به Settings > Pages.
4. در Build and deployment، گزینه Deploy from a branch را انتخاب کنید؛ Branch: `main` و Folder: `/ (root)`.
5. Save کنید و آدرس منتشرشده را باز کنید.

> نکته: GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند. اطلاعات و امنیت از طریق Supabase تأمین می‌شود. آدرس سایت را برای QR Code چاپ کنید.

## نکات امنیتی و محدودیت نسخه شروع
- نقش همه کاربران جدید به‌صورت پیش‌فرض `customer` است؛ مدیر باید از سمت دیتابیس ارتقا داده شود.
- سیاست‌های RLS اجازه تغییر منو را فقط به ادمین می‌دهند.
- کلید service_role را هرگز در کد مرورگر یا GitHub قرار ندهید.
- در این نسخه ورود ادمین با ایمیل و رمز عبور Supabase است؛ مشتری برای مشاهده منو نیاز به حساب ندارد.
- ثبت‌نام عمومی را خاموش نگه دارید مگر آنکه واقعاً بخواهید حساب مشتری ایجاد کنید.
- QR Code با آدرس فعلی صفحه ساخته می‌شود؛ پس از انتشار، آن را از سایت نهایی چاپ کنید.
- این نسخه پایه است؛ پیش از استفاده تجاری، تست دسترسی‌ها، پشتیبان‌گیری و سیاست تصاویر انجام شود.
